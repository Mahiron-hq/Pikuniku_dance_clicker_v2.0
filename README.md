## English

Greetings, Piku-fans! If you're struggling to beat the dance robot 100% and unlock the "Dancing Machine" achievement, this tool is for you.

### How it works

1. Launch: Run the program first, then the game (this helps keep the tool on top). Close other apps if you are on a low-end device.
2. Preparation: Start the dance battle, but do not press Z when the frog appears.
3. Activation: Click "Start" or press Ctrl+Shift+A. Don't worry if the program window is hidden behind the game; the hotkeys will work regardless.
4. Calibration: Once activated, the program analyzes the screen to find the center. When it's ready, you can press Z to start the dance.
5. Process: The program will automatically press the required keys for you. Just sit back and watch!
6. Finish: Once you've got the achievement, close the program using the "X" button or Ctrl+Shift+Q.

## Русский

Приветствую, Пикуниковцы! Если у вас не получается победить танцевального робота на 100% и получить достижение «Колбасер колбасит соло», то данная программа для вас.

### Как работает

1. Запуск: Запустите программу, а затем игру (это повысит шанс того, что окно программы будет поверх игры). Если у вас слабое устройство, желательно закрыть другие приложения.
2. Подготовка: Запустите танец с роботом, но при появлении лягушки не нажимайте Z.
3. Активация: Нажмите кнопку "Старт" или сочетание клавиш Ctrl+Shift+A. Если программа перекрыта окном игры, не переживайте, горячие клавиши всё равно сработают.
4. Калибровка: После запуска программа просканирует экран, найдет центр танцевального поля и начнет работу. Теперь можно нажимать Z и начинать танец.
5. Процесс: Программа будет автоматически нажимать нужные клавиши, вам остается только наблюдать.
6. Завершение: После получения достижения закройте программу кнопкой или сочетанием Ctrl+Shift+Q.
